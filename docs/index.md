# 首页

![](https://upload.wikimedia.org/wikipedia/commons/thumb/4/4f/Rhino_%28234581759%29.jpeg/512px-Rhino_%28234581759%29.jpeg)

**Rhino** 是一个完全用 Java 编写的 [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) 开源实现。它通常嵌入到 Java 应用程序中，为终端用户提供脚本支持。它作为默认 Java 脚本引擎嵌入在 J2SE 6 中。
