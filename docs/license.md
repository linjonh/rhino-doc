# 许可



Rhino 是开源软件，自 1.7R4 版本起，Rhino 适用于 [MPL 2.0](https://github.com/mozilla/rhino/blob/master/LICENSE.txt)。 1.7R4 之前的版本使用 [MPL 1.1/GPL 2.0](https://www.mozilla.org/MPL/) 许可证发布。

## 额外的许可
部分 Rhino 代码库的内容使用其他许可分发。

### Google V8 浮点转换代码及测试套件
部分浮点转换代码及部分测试套件来源于 Google V8 JavaScript 引擎，并受 V8 作者的版权保护，详见 [NOTICE.txt](https://github.com/mozilla/rhino/blob/master/NOTICE.txt)

### 部分 Rhino 调试器的许可
[rhino-tools/src/main/java/org/mozilla/javascript/tools/debugger/treetable](https://github.com/mozilla/rhino/tree/master/rhino-tools/src/main/java/org/mozilla/javascript/tools/debugger/treetable) 中的文件受 Sun Microsystems, Inc. 的版权保护，详见 [NOTICE-tools.txt](https://github.com/mozilla/rhino/blob/master/NOTICE-tools.txt)
