**Rhino JavaScript 引擎更新**

在最新版本中，我们对 Rhino JavaScript 引擎进行了重大改进，以增强性能、兼容性和安全性。这些更改包括：

1. **新增功能：**
   - **ES6 支持增强：** 添加了对更多 ECMAScript 6 功能的支持，包括Promise、Map、Set等。
   - **性能优化：** 改进了脚本执行速度和内存使用效率。
   - **调试工具升级：** 增强了调试功能，使开发者更容易查找和修复错误。

2. **已知问题修复：**
   - 修复了与 `NativeArray` 类交互时的兼容性问题，确保其在所有环境中正常工作。
   - 解决了在特定情况下导致脚本执行失败的内存泄漏问题。
   - 修正了在处理大数值时的精度问题，提升了数值计算的准确性。

3. **安全增强：**
   - 增加了对潜在恶意脚本的验证机制，提高了运行环境的安全性。

4. **文档更新：**
   - 完全重写了 API 文档，并添加了更多代码示例，帮助开发者更好地理解和使用各项功能。

通过这些改进，Rhino JavaScript 引擎在性能、兼容性和安全性方面都有显著提升。我们建议所有用户尽快升级到最新版本，以获得最佳的运行体验。
