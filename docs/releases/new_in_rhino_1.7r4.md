# Rhino 1.7R4


---
- 更新许可到 [MPL 2.0](https://www.mozilla.org/MPL/2.0/)
- 使用 `+` 进行字符串拼接速度更快
- Java 类生成更新和修复
- 更快的数字到字符串转换
- 多项正则表达式修复
- 正则表达式性能改进
- ES5 兼容性修复
- 改进了解释器性能
- 改善了 CommonJS 模块实现
- JavaScript 1.8 [生成器表达式](https://web.archive.org/web/20210502042346mp_/https://developer.mozilla.org/en-US/docs/Web/JavaScript/New_in_JavaScript/1.8)
- 多项解析器和 AST 修复
- 在 Rhino shell 中默认使用 [JavaScript 1.7](https://web.archive.org/web/20210502042346mp_/https://developer.mozilla.org/en-US/docs/Web/JavaScript/New_in_JavaScript/1.7)
- JavaAdapter 改进
- JS 到 Java 访问的修复
- 包含 Mozilla 测试套件

[修复的错误列表](https://bugzilla.mozilla.org/buglist.cgi?chfield=resolution&chfieldfrom=2011-05-09&resolution=FIXED&product=Rhino%20Graveyard&classification=Graveyard&query_format=advanced&chfieldto=2012-06-18&chfieldvalue=FIXED) 自上个版本发布以来完成的修复。
