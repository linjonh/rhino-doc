# 犀牛 1.7R4

- 更新许可证至 [MPL 2.0](https://www.mozilla.org/MPL/2.0/)
- 提升使用 `+` 进行字符串拼接的速度
- 更新并修复 Java 类生成
- 更快地将数字转换为字符串
- 修复多项 RegExp 问题
- 提升 RegExp 性能
- 修复 ES5 标准合规性问题
- 提升解释器性能
- 改进 CommonJS 模块实现
- 支持 JavaScript 1.8 [生成器表达式](https://web.archive.org/web/20210502042346mp_/https://developer.mozilla.org/en-US/docs/Web/JavaScript/New_in_JavaScript/1.8)
- 修复解析器和 AST 的多项问题
- 在 Rhino 终端中使用 [JavaScript 1.7](https://web.archive.org/web/20210502042346mp_/https://developer.mozilla.org/en-US/docs/Web/JavaScript/New_in_JavaScript/1.7) 作为默认版本
- 改进 JavaAdapter 功能
- 修复 JavaScript 到 Java 的访问问题
- 包含 Mozilla 测试套件
