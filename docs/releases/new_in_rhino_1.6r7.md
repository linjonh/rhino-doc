# 犀牛 1.6R7  

Rhino 1.6R7 是一个小型错误修复版本，紧随主要功能版本 [Rhino 1.6R6](new_in_rhino_1.6r6.md) 发布。

以下问题已被修复：  
- [391349](https://bugzilla.mozilla.org/show_bug.cgi?id=391349) 在 JDK 1.4 上启动时出现异常  
- [391350](https://bugzilla.mozilla.org/show_bug.cgi?id=391350) 数组和对象字面量的类型推断不正确  
- [392825](https://bugzilla.mozilla.org/show_bug.cgi?id=392825) ClassShutter 无法阻止通过 Java 反射 API 的访问
