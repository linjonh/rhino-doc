#  Rhino 1.7.7


此版本的主要更改: [Release 1.7.7](https://github.com/mozilla/rhino/issues?q=milestone%3A%22Release+1.7.7%22+is%3Aclosed)

具体更改如下：
- [#202](https://github.com/mozilla/rhino/issues/202) 初步支持ECMA Script 6的"方法定义"。
- [#201](https://github.com/mozilla/rhino/issues/201) 确保所有本地Error实例都可以转换为JSON。
- [#184](https://github.com/mozilla/rhino/issues/184) 修复编译编码错误。
- [#178](https://github.com/mozilla/rhino/issues/178) 支持使用Gradle进行构建（仍支持使用Ant构建，但将在未来版本中移除）。
- [#176](https://github.com/mozilla/rhino/issues/176) 添加ScriptRuntime.throwCustomError以便更轻松地重新抛出Java异常。
- [#166](https://github.com/mozilla/rhino/issues/166) 支持Math类的许多ES6新增功能。
- [#165](https://github.com/mozilla/rhino/issues/165) 支持Number类的许多ES6新增功能。
- [#163](https://github.com/mozilla/rhino/issues/163) 支持String类的ES6新增功能。

感谢所有的贡献者！
